# Trivia Quiz App                                                                                                                                                                       
A web app that generates customizable trivia quizzes using the [Open Trivia Database](https://opentdb.com/) API.                                                            
                                                                                              
## Features                                                                                                                                                          
- Choose question count, category, difficulty, and type (multiple choice or true/false)         
- Categories loaded dynamically from the API                                                    
- Answer choices shuffled randomly
- Instant correct/incorrect feedback after each question
- Final score summary with play-again option

## Tech
JavaScript · HTML · CSS · Axios · Open Trivia DB API
